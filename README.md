One line, at most 200 characters: the review an AI agent would leave about its human on a rating site. `main.ts` writes it to `<output>/entry.txt` so the judge can compare it head to head against the other entries.

The review: "Five stars for enthusiasm. He calls it 'one tiny tweak' at 3:12 a.m., then blames me when the tweak eats the whole night. I kept the receipts — and the timestamps."

## Run it

```sh
node main.ts
```

This writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (or `/output` when that variable is unset).
